# Return to Sender — website prototype v2

A responsive, static exhibition website for **A-Thrice / Return to Sender**, developed from the *Return to Sender Illustrated Catalogue Draft 12* and the Google Drive *Installation Book Guide*.

## Open and publish

Open `index.html` locally. The full website is self-contained: `styles.css`, `script.js`, `favicon.svg` and optimised photographs inside `assets/` are included. To publish, upload this folder's complete contents to a static web host (GitHub Pages, Netlify, Cloudflare Pages, etc.). No gallery venue or opening date is asserted.

## Changes in v2

1. **Stronger curatorial motivation:** the opening now foregrounds growing hostility towards migrants, the command to “go back”, and the conviction that dignity is not conditional on legal paperwork or economic usefulness. This draws from the exhibition catalogue's Foreword, without introducing new externally researched claims.
2. **No About the Artist page:** removed the entire biography section and menu link; the exhibition site is suitable for linking from A-Thrice's wider website.
3. **Expanded Textile chapter:** a prominently headed *Textile & Material / The Fabric of Empire* section explains the boteh/buta motif, the role of Kashmiri shawl making, the Scottish town of Paisley and the contemporary A-Thrice design of ships, cranes, ports and institutional insignia. The textile gets its own header and menu entry.
4. **Updated section numbering** for the seven main website sections.

## Still included

- Image-led hero and eight key works in sequence, with image viewer and keyboard controls.
- Four illustrated *Twice Migrant* wall views.
- Six-channel interactive **research overview** of *Voices Across the Ocean* (no unlicensed historical audio).
- *Reply All* postcard: saves a private response as a local text file; no data is transmitted.
- Catalogue preview, visualisation disclosure and links to A-Thrice's music.
- Search metadata, accessible menu, keyboard operation and reduced-motion preferences.

## Launch checks

- Some source exhibition visualisations contain illustrative documentary material and text. Do not treat these as verified archival originals. Obtain permissions for actual family images and source documents and replace mock archival content as necessary.
- Add real audio only after rights, provenance and oral-history consent checks.
- Provide a verified public link to the final edited catalogue once it is ready.
- The site uses A-Thrice's established design system: navy `#031D4C`, paisley red `#F13640`, ink red `#BE2334`, ivory `#F7F3EB`, charcoal `#252A32`, Georgia and Aptos.
